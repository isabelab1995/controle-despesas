Controle de Despesas

Para guardar seus lançamentos com segurança e acessar de qualquer aparelho, este site usa o Firebase (banco de dados gratuito do Google).

Como configurar (leva ~3 minutos):
1. Acesse console.firebase.google.com e crie um projeto gratuito.
2. No projeto, vá em Compilação → Firestore Database e clique em "Criar banco de dados" (modo produção).
3. Em Configurações do projeto → Geral, adicione um app da Web (ícone </>) e copie o objeto firebaseConfig.
4. Cole o objeto abaixo. Veja o README.md incluído para o passo a passo completo com imagens de referência e as regras de segurança recomendadas.
